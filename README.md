# Inventory Tracker (Configuration Status Accounting lab)

Reads `inventory.py` and calculates the total stock value.

| File | Purpose |
|------|---------|
| `inventory.py` | List of items (item_name, quantity, price) |
| `app.py` | Calculates and prints the total stock value |
| `utils/helpers.py` | `highest_stock_item()` and `lowest_stock_item()` |
| `requirements.txt` | Python dependencies |

Run with `python app.py`.
